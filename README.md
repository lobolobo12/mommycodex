# MommyCodex ♡

A macOS desktop companion for the [OpenAI Codex CLI](https://developers.openai.com/codex), built with Tauri, React, and TypeScript.

Choose **Mommy-chan**, a sweet anime companion, or **Nyx**, a commanding goth companion. Each has her own chats, preferences, expressions, and optional Fish Audio voice. This is an independent community project.

- Chat with Codex, attach visual references, steer running tasks, and follow a live checklist.
- Preview local apps, queue tasks, save project preferences, and run bounded build verification.
- Review proposed source changes before keeping them, with conflict-aware accept and undo.
- Switch between pastel and midnight themes using character portrait buttons.
- Optionally theme new games and apps with the selected companion’s building style.

Code, diffs, commands, paths, and identifiers stay unchanged by the chat styling. Fish speech is optional and requires your own API key; keys are stored in macOS Keychain.

## How it works

```
React + TypeScript webview ── invoke / Channel ──▶ Rust CodexClient ── stdio JSON-RPC ──▶ codex app-server
```

- **Rust** (`src-tauri/src/codex_client.rs`) is a thin transport bridge: it spawns `codex app-server`,
  matches JSON-RPC responses to requests, and forwards every notification and server→client request
  to the webview through an ordered Tauri `Channel`. It knows nothing about the protocol.
- **TypeScript** (`src/codex/`) owns the protocol using types generated by `codex app-server generate-ts`
  (`src/protocol/generated`). `session.ts` does the handshake, threads and turns; `store.ts` is the
  reducer for notifications; `approvals.ts` routes server requests.
- **Persona** (`persona/mommy-chan.md`) is sent as `developerInstructions` on every `thread/start` /
  `thread/resume`. Changed preferences are also appended through `thread/inject_items`, since
  an already loaded thread can ignore resume-time instruction overrides. The current voice and
  build theme apply before the next task, without changing a running turn or global Codex settings.
- **Uwuifier** (`src/uwu/`) is a deterministic remark plugin applied only to markdown text nodes,
  never to code, links, paths, identifiers or numbers. Mommy mode is a single on/off switch:
  on uses the maximum persona and maximum uwu; off uses plain professional replies. Every Mommy-mode
  message has a "show original" toggle.

## Requirements

- macOS (Apple Silicon or Intel), Codex CLI installed and logged in (`npm i -g @openai/codex`).
- Node 22.12+ (or a compatible newer version), pnpm, Rust, and Xcode Command Line Tools.
- Google Chrome for the shared browser preview.

## Develop

```sh
pnpm install
MOMMYCODEX_CWD=/path/to/project pnpm tauri dev
pnpm test                # vitest: uwuifier, remark plugin, reducer, approvals routing
pnpm test:rust           # cargo unit tests
MOMMYCODEX_LIVE_TEST=1 pnpm exec vitest run src/codex/review.live.test.mjs  # optional real, read-only Codex review
MOMMYCODEX_BUILDING_LIVE_TEST=1 pnpm exec vitest run src/codex/building.live.test.mjs  # optional themed/unthemed game comparison
cargo test --manifest-path src-tauri/Cargo.toml -- --ignored   # real app-server smoke test
pnpm gen:protocol        # regenerate protocol types after upgrading the Codex CLI
```

## Install the app and the `mommycodex` command

```sh
pnpm run install:app     # builds MommyCodex.app into ~/Applications and ~/.local/bin/mommycodex
mommycodex               # open the current directory
mommycodex ~/some/repo   # open a specific project
```

## Art

- **Included artwork:** five distinct anime expressions in `src/assets/mascot/`: idle, thinking,
  working, happy, and pouty. The companion follows live session state, and the "5 expressions"
  disclosure previews the set. Message avatars use thinking while streaming and happy on completion.
  Native app icons and the favicon use the transparent idle portrait. Prompts are recorded in
  `src/assets/mascot/ART.md`. Small avatars stay still; companion animations respect reduced motion.
- **App icon:** to replace it, use a square transparent PNG and run `pnpm tauri icon path/to/icon.png`.
  Copy the generated `src-tauri/icons/32x32.png` to `public/favicon.png` to keep the browser icon in sync.
- **Custom mascot:** replace PNG/GIF/WebP frames named `idle`, `thinking`, `working`, `happy`, `pouty`
  in `src/assets/mascot/`. Missing or broken mood images fall back to `idle`, then the built-in SVG.

The welcome screen offers starter prompts that fill the composer for you to review before sending.
You can draft while disconnected; sending becomes available once Codex and a project are ready.

## Codex controls

- **Read aloud:** each finished reply has a speaker button using Fish Audio's
  [Mommy voice by Velenuvia](https://fish.audio/m/60bd8f0f5bbc462a8fa1686dd81af336/).
  In Settings → Mommy's voice, save a [Fish API key](https://fish.audio/app/api-keys/),
  preview the voice, choose a speed, and optionally enable auto-read. The key lives in
  macOS Keychain and never in chat settings or Codex prompts. The free developer tier
  is selected initially; Standard uses Fish API credits. The app does not silently
  switch tiers. Spoken reply text is sent to Fish Audio, with code, URLs, and decorative
  faces removed. Auto-read speaks only new successful final replies in the selected
  conversation. Stop or Escape cancels generation/playback; changing conversations or
  starting a new task stops speech. Temporary audio is removed after playback or stop.
  Fish voice generation requires internet access and a valid key with access to the
  chosen tier. Replies up to 10,000 spoken characters are supported.
- **Mommy building:** the sparkle switch beside Mommy mode makes open-ended builds use an uwu
  anime mommy theme in the actual game, site, or app: characters, visuals, interactions, and visible
  copy. It works independently of the chat voice, remembers its setting, and defaults to off.
  Switch it before sending a task; finish or stop a running task before changing it. Existing
  conversations receive the updated instructions on their next task. Turning it off stops automatic
  theming without undoing existing designs. Specific user directions still take precedence, and
  fixes or reviews do not trigger a redesign. With it on, the welcome screen offers a game starter.
- **Attach files:** add up to four PNG, JPEG, WebP, GIF, or text/code files. Images can also be
  pasted into the composer. Preview and remove attachments before sending; images are limited to
  8 MB each and text to 256 KB each. Text contents are sent intact and can be expanded in the chat.
- **Follow up:** send another instruction while the current task is running. This uses Codex's
  turn steering, with the running turn's model and personality. Stop remains available separately.
  Rejected messages restore the draft and attachments so you can retry.
- **Task plan and changes:** structured plan updates and the aggregate diff appear above the chat
  when Codex produces them. These details follow the selected conversation and reset for each new task.
  They are live-session data; individual file-change cards remain in saved conversation history.
- **Review changes:** the conversation toolbar starts Codex's native review of the project's
  uncommitted changes (staged, unstaged, and untracked). Findings appear in the conversation.
  Finish or stop a review before sending another message; live follow-ups are available during ordinary tasks.
- **Search conversations:** filter the loaded conversations by name, preview, or project path.
- **Token usage:** the companion's session details show the last turn's reported token count;
  hover for conversation totals and cached-input usage.

These controls use the installed Codex CLI's generated protocol (see `src/protocol/version.ts`).
See the [official App Server documentation](https://learn.chatgpt.com/docs/app-server) for the integration overview.

## Project workbench

Open **Workbench** from the conversation toolbar. Its four tabs share the selected project.

- **Preview:** save a run command and localhost URL in Project memory, start the server, then Open
  the URL. The interactive panel shows an isolated Chrome browser; click it and use the keyboard
  to play, type or scroll. Desktop/mobile sizes, Reload, Stop preview, server output, browser
  console errors and screenshots are available. Requires local Google Chrome and Node.js 20+.
  Both the user and the coding agent operate this same browser. New threads receive the
  `mommy_preview` tool; older conversations receive a local CLI fallback. The preview browser
  has no app IPC or existing browser cookies. The agent endpoint accepts browser actions only.
- **Verify my build:** configure the check command and preview URL, then start verification.
  A dedicated conversation exercises the app using browser actions and assertions, repairs
  problems, and the harness reruns the configured checks against the final files. At most three
  attempts run. Passing requires a successful check command, recorded browser interaction,
  passing assertions, and no browser console errors. This verifies those checks, not every
  possible behavior. Output and attempt summaries stay visible; Stop verification interrupts
  the agent and the active check process.
- **Queue:** add tasks for the current project and press Run queue. Tasks run one at a time in
  their saved project, each with its own conversation. Pause prevents the next task from starting;
  Cancel interrupts the selected running task. Failure pauses the queue. Tasks persist across
  app restarts; previously running tasks become Interrupted and the queue starts paused, so
  uncertain work is never silently repeated. Queue again explicitly retries a task.
- **Project memory:** edit stack preferences, design/convention notes, run and check commands,
  and the preview URL. Memory is stored in app data per canonical project path and included in
  subsequent tasks across conversations. It does not modify global Codex settings or AGENTS.md.
- **Undo:** coding tasks capture the current working files before running and record changes
  afterward. Undo restores only that task's changed files to their pre-task contents, including
  dirty files, deleted files and binary files. It leaves the Git index untouched and refuses the
  entire restore if any affected file has changed since completion. Git-ignored files and common
  dependency/build folders are excluded, with a 20,000-file / 256 MB snapshot limit. Tasks without
  a completed snapshot cannot be safely restored; interrupted app sessions retain their baseline.

**Voice input:** hold **Hold to talk**, then release to send the recording to Fish Audio for
transcription into the editable draft. It uses your saved Fish API key and API credits; messages
are not sent automatically. macOS asks for microphone access. Cancel or Escape discards recording
or transcription; changing projects/conversations also cancels. Recording is capped at two minutes.
The companion animates while TTS plays and has an Interrupt voice button; reduced motion is respected.

### Companions

Use the **Companion** selector above chat to switch between **Mommy-chan · Sweet** and **Nyx · Goth mommy**. Nyx has original five-expression artwork and a commanding, affectionate goth personality with natural English. Selection persists across restarts and updates the next message's instructions, including existing conversations. Switching is disabled during a task. The whole interface follows the companion: Mommy-chan is pastel pink and lavender, Nyx switches the same layout to a midnight goth palette (black, violet, silver, serif headings) via the `data-character` attribute and the tokens in `src/styles/theme.css`.

Mommy mode still turns personality on/off. With Mommy building enabled, Nyx gives open-ended creative builds a midnight/violet goth anime direction; explicit requests and existing project designs take precedence. Fish TTS automatically uses a separate voice for each companion: Mommy’s soft nurturing voice and Nyx’s calm, authoritative voice. Settings provides a preview of the selected companion.

### Companion chats and review

The companion picker now opens separate chat lists and restores that companion’s talking, building, and speech preferences. Existing unassigned chats appear under Mommy-chan; use the moon/heart action on a chat to move it. New chats and queued tasks remember their companion. Edit **Preferences for Nyx / Mommy-chan** under the portrait to save instructions for future tasks.

Drop, paste, or attach reference images. **Build with this visual style** asks Codex to inspect the images’ layout and style while keeping the requested functionality. The existing image limits still apply (four attachments, 8 MB per image).

The task checklist follows Codex’s actual plan events and shows when input is needed. Portrait reactions follow task completion and check-command results. **Speak short reactions** is opt-in and uses the selected companion’s Fish voice and API credits. It does not interrupt speech or compete with automatic reply reading.

**Review before keeping** is on by default. Tasks temporarily edit source files while running. At completion the app saves the proposed changes and restores the starting source files, then opens **Workbench → Review & undo**. Inspect before/proposed contents and accept or discard. Accept and undo refuse conflicting newer edits. Proposals survive restarts; the queue pauses for review. A build verification run is collected as one proposal after its attempts finish. Accept that proposal to retain the verified files. Git-ignored files, build outputs, external side effects, and Git staging are outside source snapshots.

Validation: `node scripts/companion-ui.test.mjs` runs an isolated Chrome fixture with mocked native IPC. It does not call Codex, Fish, or the microphone.
